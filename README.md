# Stanslous Nhau UX Portfolio

## Current package
- `index.html` is the homepage.
- `enterprise-api.html`, `rise.html` and `velocity.html` are the three case studies.
- `styles.css` and `script.js` contain the shared styling and interactions.
- `assets/` contains the images and downloadable documents used by the site.
